# Shasha Liu — Personal Academic Homepage

Personal homepage of Shasha Liu, Associate Researcher at the School of Chemistry,
State Key Laboratory of Analytical Chemistry for Life Science, Nanjing University.

Live site: https://shashaliu-nju.github.io

## Structure

```
.
├── index.html              # Single-page homepage (root, required by GitHub Pages)
├── assets/
│   ├── css/style.css       # Styles
│   ├── js/main.js          # Nav highlight interaction
│   └── images/photo.jpg    # Profile photo
└── README.md
```

## Deployment (GitHub Pages)

1. Push all files to the **root** of the `main` branch of this repository.
2. Go to Settings → Pages → Branch: `main`, Folder: `/ (root)` → Save.
3. Wait 1–5 minutes, then visit https://shashaliu-nju.github.io

## Updating Content

All content is plain HTML — edit `index.html` directly, commit, and push.
No build step required.
